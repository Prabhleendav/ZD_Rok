# ZD Rok Fashion Store

A modern e-commerce platform for fashion products built with **React**, **Node.js**, and **MongoDB**.  

---

## 🚀 Tech Stack

### **Front-end**
- [React](https://es.reactjs.org/) – Front-End JavaScript library for building interactive UIs  
- [Windi CSS](https://windicss.org/) – Utility-first CSS framework  
- [Feather Icons](https://feathericons.com/) – Beautiful open-source icons  
- [Vite](https://vitejs.dev/) – Modern front-end build tooling  

### **Back-end**
- [Node.js](https://nodejs.org/) – JavaScript runtime on Chrome’s V8 engine  
- [Express.js](https://expressjs.com/) – Minimal and flexible web framework  
- [Mongoose](https://mongoosejs.com/) – Elegant MongoDB object modeling  
- [Stripe](https://stripe.com/docs/js) – Payments infrastructure for online transactions  
- [celebrate](https://github.com/arb/celebrate) – Joi validation middleware for Express  
- [JsonWebToken](https://github.com/auth0/node-jsonwebtoken) – JSON Web Token implementation  

### **Database**
- [MongoDB](https://www.mongodb.com/) – Cross-platform document-oriented NoSQL database  

---

## ⚡ Features
- Full **frontend-backend integration**  
- **User authentication and authorization**  
- **Product catalog**, categories, and detailed product pages  
- **Secure payments** via Stripe  
- **Responsive design** for mobile and desktop
